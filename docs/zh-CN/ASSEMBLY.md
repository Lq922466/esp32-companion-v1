# 制作过程与组装

[中文资料目录](INDEX.md) · [项目首页](../../README.zh-CN.md)
这是根据指定硬件整理的复现指南，不是对用户实际制作过程的逐张照片记录。已确认：3mm 瓦楞纸板、按实物手工测量裁切、现有大面包板和 UBEC。准确尺寸、紧固方式、制作时间顺序和过程照片待补充。[真实演示视频](MEDIA.md) 已提供，但不能替代完整制作记录。

1. 清点配件、检查连接。先测试 USB／主控，再分别测试 OLED、两侧红外、触摸和各舵机，记录结果。
2. 测量实际 OLED、主控、面包板、接头和舵机占用空间，直接在 3mm 纸板上标注头部与身体面板。预留屏幕窗口、红外感应路径、USB 接口、可拆检修口和线缆活动空间。在切割垫上裁切；不需要 PDF 纸模板。
3. 围绕现有大面包板和 UBEC 试装身体。保留供电接头操作空间，绝缘板底并保持通风。不要用胶封住 USB、BOOT／RESET 按钮或裸露触点。
4. 拆下两只舵盘，运行 90° 回中测试；断电后再按测得的机械中位安装舵盘，不要强扭通电的舵机轴。
5. 建议在身体／颈部采用竖直轴做 yaw，支撑头部的水平轴做 pitch。这是功能布置建议，不代表已核实实物内部安装细节。平衡头部重量、加强纸板安装点；断电后检查两轴活动空间。
6. 安装 OLED 时不要使 PCB 受力。两侧红外保持视线通畅；触摸模块放在容易触及的薄表面后方，并隔着实际纸板测试。厚度和固定方式会影响灵敏度。
7. 为两轴活动留线缆余量，固定线缆使其远离舵盘。先接共地，再接信号和符合额定要求的电源；连接前测量 UBEC。
8. 最终 V2 先空载烧录。默认 yaw 80–100°、pitch 82–98° 是软件限制，不证明机械安全。核实中位、转向和无碰撞行程后再装头部，逐步测试。
9. 在 [测试记录](TESTING.md) 补齐前保留检修口。检查发热、线缆拉力、复位稳定性和夹点间隙后再封壳。
