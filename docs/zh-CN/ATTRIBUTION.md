感谢 **Made by Z** 提供灵感并分享纸板机器人的制作思路。作者署名来自用户提供的信息。保留旧 V1 仓库中的 [原始参考链接](https://xhslink.cn/m/5y0F9KIVkvd)。该链接的作者身份、技术内容和复用授权未在本次独立核实；公开二手报道不足以证明详细原版规格或许可证。

| 项目 | 当前作品的证据 | Made by Z 原版 |
|---|---|---|
| 外壳 | 用户指定 3mm 瓦楞纸板、手工测量裁切 | 准确尺寸与材料参数未核实 |
| 模板 | 用户未使用模板，不发布裁切 PDF | 模板可用性和授权未核实 |
| 面包板／供电 | 用户指定现有大面包板、5V UBEC，12V 只进 UBEC | 用户将这些描述为差异；原版电路未核实 |
| 主控／引脚 | ESP32-C3 SuperMini，明确接线；V2 源码 GPIO 一致 | 原版板型和引脚未核实 |
| 表情／动作 | V2 包含六种表情、整脸平移、yaw／pitch、触摸点头 | 无原版源码和行为证据供比较 |

相对 **本项目旧公开仓库** 可核实的变化是：从只公开静态 OLED 程序扩展为恢复的集成 V2 固件；补充传感器、舵机和供电说明；保留 V1／历史并新增独立诊断。不能据此声称原作者没有这些功能。

没有发布原作者模板、照片、视频、群内专用固件或其他第三方素材。当前 [视频](MEDIA.md) 由本项目用户提供。致谢不等于复用授权。断言源码来源或给全部项目指定许可证前，应取得原始源码链接及适用许可。旧 README 中“未来独立 V2”的计划是历史文字，不证明当前实现独立原创。参见 [许可证建议](LICENSE-REVIEW.md)。
