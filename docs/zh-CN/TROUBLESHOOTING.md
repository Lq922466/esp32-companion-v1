# 故障排查

[English](../TROUBLESHOOTING.md) | [中文](TROUBLESHOOTING.md) | [Español](../es/TROUBLESHOOTING.md)

[中文资料目录](INDEX.md) · [项目首页](../../README.zh-CN.md)
| 症状 | 检查与处理 |
|---|---|
| 找不到烧录端口 | USB 数据线、正确端口、主控供电、关闭串口占用软件；核实该板 BOOT／RESET 方法 |
| OLED 扫描无 ACK | 供电／共地、SDA/SCL 是否接反、GPIO 编号、焊点、兼容上拉和短线 |
| 出现 0x3D 而非 0x3C | 核实实际模块；最终程序只使用 0x3C，0x3D 仅诊断报告 |
| 有 ACK 但黑屏 | ACK 只说明总线应答；检查 SSD1306／SH1106 类型、128×64 分辨率、屏幕／复位／供电并实测 |
| HELLO 可见但无脸 | 1.5s 后采集串口，检查帧计数和缓冲，核对实际上传源码；不能只凭串口推断显示 |
| 红外一直有效 | 分别读原始电平，调电位器、移除反射面，检查环境光与输出极性 |
| 触摸一直有效 | 检查 TTP223 锁存／瞬时模式和极性跳线；固件预期瞬时 HIGH，有实际外壳时隔壳测试 |
| 舵机不动 | UBEC 电压、共地、信号脚、舵机使能、接头方向；单只空载测试 |
| 舵机方向相反 | 空载测试后再修改对应方向参数；确认机械 yaw／pitch 分配 |
| 动作时抖动／复位 | 电压下降、峰值电流、地线连续性、过细／过长导线、面包板接触与机械堵转；断开舵机隔离排查 |
| 触摸不再次触发 | 先释放再触摸，等待 2200ms 冷却；上电已按住时有意不触发 |
| 两侧红外同时有效 | 脸部和 yaw 回中是预期行为，不是优先级故障 |

记录实际观察、电源测量、准确固件哈希和串口日志。不要用预期结果代替缺失测试。参见 [独立测试](COMPONENT-TESTS.md)、[测试记录](TESTING.md)。
