# 安全与注意事项

[English](../SAFETY.md) | [中文](SAFETY.md) | [Español](../es/SAFETY.md)

[中文资料目录](INDEX.md) · [项目首页](../../README.zh-CN.md)
- 12V 适配器只接额定支持该输入的 UBEC。连接舵机前核实输出 5V 与正确极性。
- 本指南用 USB 给主控供电。12V 不得进入逻辑模块、舵机或 ESP32 引脚；不要用另一电源向 USB 反向供电。
- 所有设备共地，检查 3.3V 电平兼容性、电流容量与绝缘；重新接线前断开电源。
- 舵机启动立即命令 90°。首次启动先拆舵盘，软件无法知道机械中位。手指、线缆和纸板避开夹点；堵转、异响、抖动或发热时立即断电。
- 不要阻挡舵机轴执行指令。平衡头部重量，确认固定牢靠。不同仿制 SG90 的行程和脉宽校准可能不同。
- 纸板可燃。UBEC 和接头保持通风，发热、冒烟或异味时停机。不要无人看管运行，也不要用胶覆盖带电连接。
- 在切割垫上操作并远离手部。热熔胶冷却后再安装电子器件；避免导电紧固件、胶体压力损伤电路板。

接线见 [WIRING](WIRING.md)，首次测试见 [COMPONENT-TESTS](COMPONENT-TESTS.md)。
