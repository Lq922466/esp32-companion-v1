# 接线说明

[中文资料目录](INDEX.md) · [项目首页](../../README.zh-CN.md)
接线前断电。GPIO 编号指 ESP32-C3 的 GPIO，不是排针的物理位置。

| 设备 | 信号 | GPIO | 供电 |
|---|---|---:|---|
| OLED | SDA / SCL | 0 / 1 | 模块支持时用 3.3V；共地 |
| SG90 Yaw | 信号 | 4 | UBEC 5V；共地 |
| SG90 Pitch | 信号 | 5 | UBEC 5V；共地 |
| 左红外 | 数字 OUT | 6 | 电源和输出必须兼容 3.3V |
| 右红外 | 数字 OUT | 7 | 电源和输出必须兼容 3.3V |
| TTP223 | OUT | 10 | 兼容模块用 3.3V；共地 |

```text
12V 适配器正／负极 → UBEC 输入正／负极
UBEC 5V 输出 → 两只舵机 V+
UBEC 输出 GND → 舵机 GND 和 ESP32 GND
USB → ESP32 供电和烧录
ESP32 3.3V → 兼容的 OLED／触摸／红外模块
ESP32 GPIO → 上表对应的模块信号
```

**禁止将 12V 接到 ESP32、OLED、传感器、舵机或面包板逻辑电源轨。** 插入舵机前先测量 UBEC 输出和极性。未核实主控电源电路前，不要将外部 5V 与 USB 5V 并接。

ESP32-C3 使用 3.3V 输入电平。如果红外模块需要 5V 供电或输出 5V，必须核实电路并采用合适的电平转换。固件中的上拉不能转换电压。I²C 上拉保持在 3.3V 一侧。以实际开发板和模块资料为准，不只看线色或商家图片。

保留现有大面包板，确认电源轨是否在中间断开，标明 3.3V、5V 和 GND。舵机电流优先采用额定容量合适的直接连接，避免长面包板路径和细跳线。不要让 GPIO 排针承受机械载荷。SG90 线色可能不同，应在实际器件上确认信号、正极和负极。参见 [安全](SAFETY.md)。
