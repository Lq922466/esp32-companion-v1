# ESP32 陪伴机器人 V1

**INNNX. · Robots & IoT**

**简体中文** | [Español](README.es.md) | [English](README.en.md) · [项目首页](../README.md)

## 1. 项目简介

这是基于 ESP32 的陪伴机器人原型。当前仓库公开的是 OLED 表情显示模块的 Arduino 草图，不代表完整机器人已经完成。V1 受参考项目启发，仍在开发中。

## 2. 项目目标

- 探索陪伴机器人制作，按自己的需求调整硬件材料和配置。
- 以现有 OLED 表情显示代码为起点，逐步开展硬件验证。
- 如实记录代码、测试结果和版本状态，区分实际成果与未来计划。

上述是开发目标，不是已完成的成果。

## 3. 硬件与技术

| 项目 | 基于现有文件确认的信息 |
| --- | --- |
| 开发板 | ESP32 系列；具体型号需按实物确认 |
| 显示屏 | SSD1306 OLED，128×64 |
| 通信 | I²C；代码地址 `0x3C` |
| 引脚 | SDA GPIO 0、SCL GPIO 1；实际板型适用性需确认 |
| 环境 | Arduino IDE、ESP32 板卡支持 |
| 语言与依赖 | Arduino/C++、Wire、Adafruit GFX、Adafruit SSD1306 |
| 程序 | [`firmware/oled-face/oled-face.ino`](../firmware/oled-face/oled-face.ino) |
| 串口 | `115200` 波特率 |

这不是经实物验证的完整物料清单。其他材料、供电方案和硬件调整明细尚未记录。

## 4. 已实现的功能

这里“已实现”仅指代码已经编写：

| 功能 | 代码状态 | 硬件验证 |
| --- | --- | --- |
| 初始化 I²C 和 SSD1306 | 已编写 | 未确认 |
| 清空缓冲区、绘制双眼与嘴巴、提交显示 | 已编写；静态图形 | 未确认 |
| 串口状态提示 | 已编写；成功分支输出 `OLED OK!`，失败分支输出 `OLED ERROR` 并停留 | 未确认 |

双眼使用 `fillRoundRect()`，嘴巴由两条 `drawLine()` 组成，`display.display()` 提交显示缓冲区。`loop()` 为空。代码没有表情动画、对话、联网、语音、运动控制或自主行为实现。

## 8. 使用说明及已知限制

1. 按实际 ESP32 板型核对 OLED 接口、供电、电平和接线。确认 SDA GPIO 0、SCL GPIO 1 与地址 `0x3C` 适用；它们不保证适合所有 ESP32 板型。
2. 在 Arduino IDE 安装相应 ESP32 板卡支持及 Adafruit GFX、Adafruit SSD1306 库。
3. 打开上述草图，选择正确板型和端口，核对设置后自行编译、上传。
4. 以 `115200` 波特率查看串口，并实际观察 OLED。记录结果及所用硬件，不将预期效果当作测试记录。

本次没有实测该流程。代码只绘制一次静态面部，初始化失败后停留，`loop()` 为空。仓库没有完整接线图、完整物料清单、硬件验证证据或原作者素材授权记录。本次未上传密钥、个人信息或第三方素材。
