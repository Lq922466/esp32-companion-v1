1. Confirm authorship/provenance of V1, V2 and the earlier OLED sketch; check whether any code was copied from Made by Z or another author and obtain the applicable permission/license.
2. Keep required original notices and distinguish owned code/documentation from third-party material. Acknowledgement is not a substitute for permission.
3. For code the owner is entitled to license, MIT is a possible permissive choice; apply only after the owner confirms scope and copyright holder. Original text and physical media may be licensed separately if desired.
4. Libraries/core are installed dependencies, not vendored in this package. Review licenses at their pinned versions: Arduino-ESP32, ESP32Servo, Adafruit GFX, SSD1306 and BusIO. Do not assume one license covers all dependencies or distributed binaries.
5. Keep the creator's template/group firmware/photos/videos excluded until explicit permission exists. This package contains no cutting PDF.

This file records unresolved permissions and a suggested workflow; it is not a license grant or a claim of legal clearance. Publish code only after clarifying unresolved third-party provenance.
